# 🛒 TechStyle - Modern E-Commerce Single Page Application (SPA)

TechStyle is a fully functional, highly responsive E-Commerce Single Page Application (SPA) built with pure **HTML5, Tailwind CSS, and Vanilla JavaScript**. It features dynamic product rendering, advanced real-time filtering, multi-directional sorting, and cross-session cart persistence.

🚀 **Live Demo:** [https://kartheek1708.github.io/techstyle-ecommerce/](https://kartheek1708.github.io/techstyle-ecommerce/)

---

## ✨ Key Features

* **⚡ Dynamic Product Generator:** Generates a dynamic 100-product catalog with category-specific logic, price boundaries, and unique Unsplash visual signatures.
* **🔎 Real-Time Search:** Instant keyword lookup matching product titles and descriptors.
* **🎛️ Advanced Filtering System:** Multi-category selection checkboxes paired with dynamic price range sliders.
* **⇅ Multi-Directional Sorting:** Sort products dynamically by price (*Low-to-High* or *High-to-Low*).
* **🛒 Interactive Cart Drawer:** Slide-over cart functionality with quantity controls, subtotal tracking, and persistent state management using native `localStorage`.
* **📱 100% Mobile Responsive:** Clean utility-first styling with Tailwind CSS ensuring dynamic layouts across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack & Utilities

* **Frontend Framework:** Plain HTML5 & Vanilla JavaScript (ES6+)
* **Styling & Design:** Tailwind CSS (CDN Integration) & FontAwesome Icons
* **Data Handling & Persistence:** Browser `localStorage` API
* **Assets Engine:** Unsplash Dynamic Image CDN
* **Deployment & Hosting:** GitHub Pages
